## About Me

I am a cybersecurity researcher specializing in **Application Security** and **API Security**. My work focuses on identifying, validating, and responsibly disclosing real-world vulnerabilities in production software, backed by manual testing and systematic root-cause analysis.

I approach security from both offensive and defensive angles: understanding how systems break, proving impact with evidence, and writing findings in a way that helps teams fix them fast.

- Focused on Application Security, API Security, and open-source vulnerability research
- Actively documenting a hands-on AWS and Cloud Security learning journey
- Contributing to bug bounty programs (HackerOne, Bugcrowd) and government VDPs
- Founder of **0xTraceSec**, a cybersecurity community
