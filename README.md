## About

I am a Security Researcher and Penetration Tester focused on web and API security. I find and validate vulnerabilities in open-source software and live targets, and report them with clear, reproducible evidence.

I am moving into Application Security through secure code review and manual exploitation. I share technical write-ups on [Medium](https://kashifsec.medium.com/).
